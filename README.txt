# AR Buddhist Game Station — Prototype 0.9

0.9 = ระบบผู้เล่นและคะแนนสะสมทั้งสถานี

เพิ่ม:
- คะแนนสะสมจากทุกภารกิจใน session เดียว
- ระบบระดับผู้เล่น:
  0–199 = ผู้เริ่มต้นทำความดี
  200–399 = นักสร้างความดี
  400–599 = นักสืบทอดวิถีพุทธ
  600+ = ทูตวิถีพุทธ
- แสดงคะแนนสะสมและระดับบนเมนู
- เมื่อภารกิจ 1 สำเร็จ คะแนนจะเข้าสู่คะแนนรวม
- หน้าจอ Mission Complete แสดงคะแนนรวม + ระดับ
- กลับไปเลือกภารกิจต่อได้
- ปุ่มเริ่มคะแนนใหม่

หมายเหตุ:
Prototype 0.9 ใช้ sessionStorage เพื่อเก็บคะแนนระหว่างการเล่นในแท็บ/เซสชันเดียว
ยังไม่ใช่ระบบฐานข้อมูลหรือบันทึกถาวรของผู้เล่น
